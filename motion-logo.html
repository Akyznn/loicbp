Coller du code SVG

Le presse-papiers ne contenait pas de code SVG. Colle-le dans le champ ci-dessous, ou suis ces étapes.
  1. Illustrator : sélectionne ton logo puis copie. Si rien ne se colle, va dans Préférences › Gestion du presse-papiers, active la copie en code SVG, et recopie.
  2. Illustrator, autre méthode : Fichier › Exporter › Exporter sous… › SVG, puis glisse le fichier ici.
  3. Figma : clic droit sur le calque › Copier/Coller sous › Copier en SVG.
